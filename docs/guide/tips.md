# 效率技巧

收录日常高频场景的具体做法，按需查阅。

## 整理会议记录

把记录丢给 WorkBuddy 之前，先补两样东西：**会议目标**和**你关心的结论类型**。这样输出才不会变成流水账。

```text
目标：从会议记录中提取决策和待办
输入：[会议记录]
输出：两部分——「已定事项」用列表，「待办」用表格（负责人 / 事项 / 截止）
限制：只记录明确提到的内容，不推测
```

## 写周报

周报最省事的方式是平时留痕，周五只做整理：

1. 每天在固定文档里记一条「今天完成了什么」
2. 周五让 WorkBuddy 把这些条目按项目归类
3. 人工补齐"下周计划"和"风险"两项

## 处理长文档

面对长材料时，不要一次性要求总结全文：

- 先让它列出**章节结构**，确认范围
- 再针对你真正关心的章节逐段处理
- 最后把几段结果合并成你要的格式

## 减少返工的小习惯

| 场景 | 做法 |
| --- | --- |
| 输出格式不对 | 在输入里给出一段示例格式 |
| 结果太泛 | 补上判断标准和限制条件 |
| 多次修改仍不满意 | 停下来重写目标，而不是继续追加要求 |

::: tip
把所有"用得顺手"的输入保存成模板，下次直接复用，是收益最高的习惯。
:::

## 回到主线
