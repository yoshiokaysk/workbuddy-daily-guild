# 指南概览

欢迎使用 **WorkBuddy 日常工作指南**。这份指南只解决一件事：让你在日常工作中，更快、更稳地用好 WorkBuddy。

## 这份指南适合谁

- 已经安装好 WorkBuddy，想把它真正用起来的同学
- 每天有大量重复、琐碎任务的同事
- 希望建立一套可复用工作节奏的小团队

## 指南包含什么

| 章节 | 内容 | 什么时候看 |
| --- | --- | --- |
| [快速开始](/guide/getting-started) | 最小可用配置与第一次任务 | 刚上手时 |
| [日常工作流](/guide/daily-workflow) | 一天中的固定节奏与任务组织 | 想建立习惯时 |
| [效率技巧](/guide/tips) | 高频场景的具体做法 | 遇到具体问题时 |
| [日常工作应对指南](/guide/handbook/) | 按场景给出可直接照做的步骤和模板 | 想系统掌握或深入某个场景时 |

::: tip 推荐
如果想真正把 WorkBuddy 用到日常工作里，重点看 **[日常工作应对指南](/guide/handbook/)**。全书 16 章加附录，覆盖会议、写作、数据、沟通、学习、时间管理等高频场景，每章都配可复制的提示词模板。
:::

## 怎么用这份指南

1. **先跑通**：从[快速开始](/guide/getting-started)做一遍，确保基本流程可用。
2. **再固定**：按[日常工作流](/guide/daily-workflow)安排一周，形成节奏。
3. **随用随查**：遇到具体问题时翻[效率技巧](/guide/tips)。

::: tip
不需要一次读完。把这份指南当成工具书，需要时回来查对应章节即可。
:::

## 一个基本原则

> 把决策成本前置，把执行动作简化。

越是每天都要做的事，越应该固定下来——固定的输入、固定的步骤、固定的输出。这样 WorkBuddy 才能真正替你省时间，而不是增加新的维护负担。
