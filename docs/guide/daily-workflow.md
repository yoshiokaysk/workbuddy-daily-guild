# 日常工作流

这一章把 WorkBuddy 放进一天的固定节奏里，减少临场决策。

## 一天的三个节点

### 早上：规划

- 把当天待办按「必须完成 / 可以延后」分成两堆
- 挑出 1–2 件适合交给 WorkBuddy 的重复性任务
- 为这些任务准备好输入材料，避免中途找资料

### 中午：执行

- 集中处理早上筛出的任务，而不是随时被打断
- 每个任务都按同一套输入模板提交，保持输出可比较
- 对结果只做「通过 / 返工」两种判断，不反复微调

### 下班前：收尾

- 把当天确认可用的输出归档到固定位置
- 记录 1 条「下次可以做得更好」的改进点
- 给第二天的任务留一句备注，减少早上启动成本

## 让流程稳定的三个约定

1. **固定输入**：同一类任务用同一套模板。
2. **固定位置**：输出归档到同一个目录或文档。
3. **固定复盘**：每周只花 10 分钟看一次改进点。

> 工作流的价值不在于每一步多聪明，而在于每天都差不多。

## 一周示例

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 周一早 | 汇总本周目标 | 一份本周待办 |
| 周二至周四 | 按节点执行 | 每日输出归档 |
| 周五下午 | 复盘改进点 | 一条下周调整 |

::: tip
如果某一天节奏被打乱，不用补做。第二天回到固定节点即可。
:::
