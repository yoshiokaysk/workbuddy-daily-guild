# 快速开始

这一章目标很小：用最短路径跑通第一次任务。

## 准备工作

- 已安装 WorkBuddy，并能正常打开会话
- 有一个明确、可验证的小任务（例如「把一段会议记录整理成三条待办」）

## 第一次任务

按下面的顺序做一遍：

1. **说清目标**：一句话说明你要的结果，而不是过程。
2. **给足上下文**：把原始材料、背景和限制条件一并给出。
3. **指定输出格式**：告诉它你要列表、表格还是段落。
4. **检查结果**：确认输出是否可用，再决定是否继续。

例如：

```text
把下面的会议记录整理成三条待办，每条一行，包含负责人和截止时间：
[粘贴会议记录]
```

## 一个好用的输入模板

日常任务大多可以套这个结构：

```text
目标：<一句话说明要什么结果>
背景：<必要的上下文>
输入：<原始材料>
输出：<格式要求，如表格 / 三条要点 / 不超过 200 字>
限制：<不能做什么，如不要新增未提及的信息>
```

## 常见误区

| 误区 | 更稳的做法 |
| --- | --- |
| 一次塞进太多任务 | 拆成几次，每次只验证一个结果 |
| 只说「帮我优化一下」 | 说明优化目标和判断标准 |
| 不看输出直接用 | 先抽检关键字段是否正确 |

::: tip
第一次不用追求完美，重点是建立「说清目标 → 检查结果」的闭环。
:::
