# 第 14 章 搭建个人工作流

前面十三章讲的是单个任务怎么做。这一章把它们串成一套稳定的日常节奏——不是让你记住所有模板，而是让正确用法变成默认动作。

## 工作流的三个固定

一套能跑起来的工作流，靠三个"固定"：

1. **固定输入**：同一类任务用同一个模板，不再每次组织语言。
2. **固定位置**：模板存一处、产出存一处、复盘记一处。
3. **固定节奏**：每天/每周什么时候做什么，形成习惯。

缺任何一个，工作流都会退化为"想起来才用"。

## 一天中的三个节点

### 早上：规划（10 分钟）

```text
1. 打开任务清单，按第 13 章排今天的 priorities
2. 挑出 1–2 件适合交给 WorkBuddy 的重复性任务
3. 把要用的模板打开，放好
```

关键在"前一天晚上就把材料和模板准备好"。早上不要花时间找东西。

### 白天：执行（随时）

```text
遇到任务 → 判断属于哪一类（第 1 章）
        → 选对应模板（附录速查表）
        → 填入输入 → 下发
        → 三层验收（第 7 章）→ 归档
```

这套动作熟练后，单个任务耗时应该稳定在几分钟，不再有"怎么问"的犹豫。

### 下班前：收尾（5 分钟）

```text
1. 把当天确认可用的产出存到固定位置
2. 用一句话记录"今天哪个模板好用/不好用"
3. 给明天的任务留一句备注
```

第 2 条是模板迭代的来源（第 5 章）。一周下来，你会积累 5 条改进记录，月底回头看，模板质量明显不同。

## 一周节奏

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 周一早 | 排本周计划，标注重点 | 本周任务表 |
| 周二至周四 | 按节点执行，记录模板问题 | 每日产出 + 改进记录 |
| 周五下午 | 周复盘 + 模板更新 | 一份复盘 + 更新后的模板 |

周五的模板更新只花 10 分钟，但它是工作流能持续进步的关键。不做这一步，三个月后你的模板还是最初那版。

## 工具链怎么配合

不需要复杂工具。三个位置就够：

```text
【模板区】一个文档，存所有提示词模板（第 5 章）
【产出区】一个固定目录，存所有确认可用的结果
【复盘区】一个文档，按日期记录改进点
```

关键不是工具多高级，而是**位置固定、随手能到**。存在收藏夹深处、需要翻找的东西，等于不存在。

### 命名规则

产出按"日期—场景—主题"命名：

```text
2026-11-19—周报—运营组
2026-11-19—会议纪要—产品评审
2026-11-19—客户邮件—延期说明
```

这样三个月后回头找，按文件名就能定位。

## 把工作流跑起来的最小步骤

不要一次设计完美工作流。按这个顺序：

1. **第一周**：只选一个任务（第 3 章），用它验证模板。
2. **第二周**：加第二个任务，同时开始记录改进点。
3. **第三周**：固定"早上规划、下班收尾"两个节点。
4. **第四周**：做第一次周复盘，更新模板。

一个月后，工作流自然成型。一开始就设计十几个节点的人，通常两周后就放弃了。

## 工作流失效的信号

出现下面情况，说明工作流需要调整：

| 信号 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 想起来才用 | 没固定节点 | 加上"早上规划"这一步 |
| 每次都重新写提示词 | 模板没存好 | 模板放随手能到的地方 |
| 结果还是常常不能用 | 模板限制不够 | 按第 7 章补限制条件 |
| 产出找不到 | 没有固定位置 | 设产出目录+命名规则 |
| 用了几周没进步 | 没做复盘 | 加上周五的 10 分钟复盘 |

## 一个完整的工作流示例

某运营人员的一天：

```text
09:00 打开任务表，确定今天重点：活动方案初稿、数据日报
09:10 打开"数据日报"模板，填入昨天的数据
09:15 拿到初稿，抽样检查 → 存到 产出区/2026-11-19—数据日报
10:00 写活动方案：先用"提纲模板"出结构，确认后再用"正文模板"
11:30 出声读一遍方案，改掉两处空话 → 归档
14:00 群里有人提了个模糊需求 → 用"对齐模板"列待确认问题，发给对方
17:30 收尾：记录"提纲两步法很好用，数据日报模板要加空值规则"
```

这一天里，WorkBuddy 参与了 4 件事，但没有一件是"全自动"——每一步都有他的判断和验收。

## 小结

- 工作流靠三个固定：固定输入（模板）、固定位置（模板区/产出区/复盘区）、固定节奏（每日三节点、每周一循环）。
- 工具不用复杂，三个固定位置就够；产出按"日期—场景—主题"命名。
- 用四周时间逐步建立工作流，不要一次设计完美。
- 出现"想起来才用""每次重写提示词"等信号时，按对照表调整。
