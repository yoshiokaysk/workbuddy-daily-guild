# 导读：这份指南怎么用

这是一份写给"每天都要用 WorkBuddy 处理实际工作"的人的实战手册。它不介绍产品的发展历史，也不展开讲 AI 的原理，只回答一个问题：**明天上班，具体怎么用 WorkBuddy 把活干得更快、更稳？**

## 这本指南和站点其他内容有什么区别

站点里已经有几类内容，容易混淆，先分清：

| 内容 | 定位 | 适合什么时候读 |
| --- | --- | --- |
| 日常指南（快速开始、工作流、技巧） | 几页速览，先跑起来 | 第一次接触、想快速了解 |
| 实战蓝皮书 | 系统教程，28 章 | 想完整学习产品能力 |
| 个人案例集 | 真实实践案例 | 想看别人怎么做、找灵感 |
| **本指南** | **按工作场景组织的步骤手册** | **日常遇到具体任务，照着做** |

简单说：蓝皮书教你"WorkBuddy 有哪些功能"，这本指南教你"周一早上那堆活，先交给它哪一件、怎么交代、怎么验收"。

## 适合谁读

- 已经在用 WorkBuddy，但常常"问了等于没问"，结果要自己重写
- 每天有大量重复、琐碎、格式固定的任务
- 想建立一套稳定流程，不再每次都临场发挥
- 团队协作中需要统一用法，避免各用各的

如果你还没安装或跑通第一个任务，先去读本站的[快速开始](/guide/getting-started)，再回来。

## 全书结构

全书四篇，加一个附录：

- **第一篇 基础认知**（3 章）：先搞清楚什么该交给它、什么不该，以及怎么盘点自己的工作。篇幅最短，但决定后面所有方法是否有效。
- **第二篇 核心方法**（4 章）：说清任务、模板化、对话节奏、验收纠错。这是全书的"内功"，后面每个场景都会用到。
- **第三篇 场景实战**（6 章）：会议信息、文档写作、表格数据、沟通协作、学习知识、时间任务。这是全书篇幅最大的部分，按场景给出可以直接照做的步骤和模板。
- **第四篇 系统化与进阶**（3 章）：把方法固化成个人和团队的工作流，以及必须避开的坑。
- **附录**：常用指令模板速查、场景—方法对照表、术语表。

## 怎么用这本书

### 用法一：按场景查（推荐）

遇到具体任务时，直接翻到第三篇对应章节。比如"下周要写周报"，就看第 9 章"文档与内容写作"，复制里面的模板改一改。

### 用法二：按顺序学

如果你是第一次系统梳理自己的用法，从第 1 章顺读到第 16 章。重点读第二篇，它决定了你后面所有场景的效果。

### 用法三：只看模板

附录里有全部模板的速查表。用熟之后，平时只看附录就够了。

## 关于书中的提示词示例

书中所有提示词都用代码块标出，可以直接复制。方括号 `[ ]` 里的内容是需要你替换的部分，例如：

```text
把下面的会议记录整理成三条待办，每条一行，包含[负责人]和[截止时间]：
[粘贴会议记录]
```

使用时把方括号连同里面的文字一起替换成你的实际内容。

::: tip
不要照抄示例。示例的价值是展示结构，真正有效的是你把具体背景填进去。同一个模板，填的信息越具体，结果越可用。
:::

## 一个贯穿全书的原则

> 人定标准，AI 执行；人做判断，AI 出初稿。

这本指南里所有方法，本质上都在落实这一句话。凡是试图把判断责任也交出去的用法，最后都要付出返工的代价。
