# 第 16 章 避坑与安全边界

这一章把前面散落在各处的"不要"集中起来，形成一张完整的避坑清单，并单独讲清楚安全边界。

## 十个常见误区

### 误区一：一次塞太多任务

**表现**：一段提示词里要求"整理会议记录、写周报、再帮我回复邮件"。
**后果**：每项都做得浅，你还不好判断哪项对。
**修正**：一次一件事。拆成三次下发。

### 误区二：期待一次到位

**表现**：第一版不满意就认为不好用。
**后果**：反复重来，比自己做还慢。
**修正**：按第 6 章的修正话术推进，三轮之内收敛。

### 误区三：目标写动词不清

**表现**："处理一下""优化一下""看看这个"。
**后果**：它只能猜，方向常常错。
**修正**：用明确动词（整理、写、列出、改成）+ 明确对象。

### 误区四：描述材料而不给材料

**表现**："会议记录有点长，主要说了进度"。
**后果**：它基于你的描述再加工，信息两次转述后丢失。
**修正**：直接贴原文；太长就分批。

### 误区五：不给输出格式

**表现**："整理成表格"就完了。
**后果**：列不对、行数不对、还得返工。
**修正**：写清列、行数、字数、语气。

### 误区六：限制写成期望

**表现**："希望准确一点""尽量简洁"。
**后果**：它不知道边界在哪。
**修正**：写成可执行的规则——"缺失数据写未提供""总字数不超过 400 字"。

### 误区七：编造的数据没发现

**表现**：结果里有看着合理但你没提供的数字。
**后果**：错误数据被写进对外材料。
**修正**：严格执行第 7 章的来源检查；限制里写"不编造"。

### 误区八：让它替你做判断

**表现**："这个项目该不该做？"
**后果**：它不知道隐含信息，判断可能错，责任却在你。
**修正**：让它列利弊，你决定（第 2 章）。

### 误区九：放任风格漂移

**表现**："写得专业一点"，结果和你想要的完全不同。
**后果**：每轮都在调语气。
**修正**：给一句示例风格，比形容词有效。

### 误区十：用了不反思

**表现**：同一个模板用三个月，从没改过。
**后果**：效率停在起点。
**修正**：每周记录改进点，每月更新模板（第 14 章）。

## 安全边界

### 数据分级

把你要输入的内容按敏感程度分级：

| 级别 | 例子 | 能否输入 |
| --- | --- | --- |
| L1 公开 | 公开资料、通用问题 | 可以 |
| L2 内部 | 内部流程、非敏感业务数据 | 按公司规定，通常可以 |
| L3 机密 | 客户数据、合同、财务、人事 | 通常不可以，需脱敏或不用 |
| L4 高度机密 | 密钥、密码、未公开战略 | 绝对不要输入 |

### 三条硬规则

1. **L3 及以上不输入**——除非公司明确规定允许且有相应保护。
2. **脱敏后输入**——如果必须处理敏感材料，把人名、金额、客户名等替换为代号。
3. **对外内容人工审批**——AI 生成的对外材料，必须人工核对和审批后发出。

### 脱敏示例

```text
原内容：
"张伟向客户 ABC 公司的李娜报价 85 万元，折扣 12%"

脱敏后：
"[员工A]向客户[客户X]的[联系人B]报价[金额X]，折扣[比例Y]"

目标：把这段脱敏后的内容整理成报价记录
输出：表格「员工 / 客户 / 联系人 / 金额 / 折扣」
限制：代号不要还原，保持脱敏状态
```

### 合规检查清单

下发任务前，对涉及的数据问四个问题：

- 这是公开信息、内部信息还是机密信息？
- 公司是否允许把这类信息输入 AI 工具？
- 是否需要脱敏？
- 这个产出会不会对外发出？如果会，谁审批？

::: warning
不确定时，按"不输入"处理。一次数据泄露的代价，远大于少省的那点时间。
:::

## 质量红线

除了数据安全，还有几条质量红线，违反任何一条都不该交付：

| 红线 | 说明 |
| --- | --- |
| 编造数据 | 任何未提供的数字、人名、时间 |
| 越权承诺 | 替公司或个人做超出授权的承诺 |
| 事实错误 | 与原始材料冲突的表述 |
| 未核对的对外内容 | 没有经过人工核对和审批 |
| 责任转移 | 把"判断"当成 AI 的结论直接采用 |

## 出错后的处理

如果已经发现了问题（比如错误数据已经发出去）：

1. **立即止损**：撤回、更正、通知相关人。
2. **记录原因**：是提示词没写限制？还是验收没做？还是数据没脱敏？
3. **更新规范**：把这次教训写进模板限制或团队约定。
4. **不要掩盖**：尤其是数据错误，越早说明代价越小。

## 一张总检查表

每次交付前，对照这张表：

```text
来源：所有数字/人名/时间都来自输入材料？
判断：结论是我认可的，不是它替我决定的？
格式：能直接用，不用再调格式？
边界：没有越权承诺，没有敏感信息？
审批：对外内容已经过人工核对和审批？
```

五项全过，才能交付。

## 小结

- 十个误区集中在：贪多、求一次到位、目标动词不清、不给材料、不给格式、限制写成期望、忽视编造、让 AI 做判断、放任风格、不用不反思。
- 数据分四级：L3 及以上不输入，必要时脱敏，对外内容人工审批。
- 三条硬规则：L3 不输入、脱敏后输入、对外人工审批。
- 质量红线：编造数据、越权承诺、事实错误、未核对对外内容、责任转移。
- 出错立即止损、记录原因、更新规范，不要掩盖。
- 交付前过五项总检查表：来源、判断、格式、边界、审批。
