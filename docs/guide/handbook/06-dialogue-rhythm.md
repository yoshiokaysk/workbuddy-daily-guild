# 第 6 章 对话节奏：推进、追问与重来

大多数任务不是一次说完就能完成的。这一章讲多轮对话怎么推进：什么时候继续、什么时候追问、什么时候推倒重来。

## 一轮完整对话的三个阶段

```text
第 1 轮：给完整任务 → 拿到初稿
第 2~N 轮：针对初稿做修正 → 逐步收敛
最后一轮：确认可用 → 收尾归档
```

很多人卡在第 2 轮：要么不知道怎么提修改意见，要么每次都重新描述整个任务。这一章重点解决第 2 轮。

## 修正初稿的四种话术

### 话术一：指出偏差，而不是重写

初稿方向对但有偏差时，不要重新发一遍完整提示词，直接指出偏差。

```text
初稿太啰嗦，把背景介绍全删了。
保留「已定事项」和「待办」两部分，
其他不要，直接输出这两部分。
```

关键：说清楚"保留什么、删什么"，而不是"再写一遍"。

### 话术二：引用具体位置

初稿某一段不对，指明是哪一段。

```text
第 3 段"建议加强跨部门沟通"太空了。
改成具体动作：每周三拉一次 15 分钟同步会，
参会人列出来。其余段落不动。
```

"其余段落不动"很重要，否则它可能借机重写全篇，把你满意的部分也改掉。

### 话术三：给一个正确示例

当你说不清想要什么，但看到对的能认出来时，给示例。

```text
语气不对，你写的太正式了。
参考这个风格：
「这版先这样，数据源下周换新的，到时候再更新。」
——就这个口吻，简短、口语化但专业。
按这个风格重写全文。
```

示例比形容词（"口语化一点""活泼一点"）有效得多。

### 话术四：缩小范围

初稿太散，让它聚焦。

```text
现在写得太全了，我只要"风险"这一个部分。
从全文里抽出所有风险相关内容，
按严重程度排序，每条一行，不超过 5 条。
```

## 什么时候该继续，什么时候该重来

用这个判断表：

| 初稿状态 | 处理方式 |
| --- | --- |
| 方向对，细节要改 | 继续，用上面的修正话术 |
| 方向对，但漏了一块 | 继续，让它补那一块："再加一段 X" |
| 格式对但内容空 | 继续，补充输入材料后重写 |
| 方向完全错 | 重来，但先补一句话说明为什么错 |
| 连续两轮都不对 | 停下，回到第 4 章检查五要素 |

### 重来时怎么说

重来不是把原话再发一遍。要说清楚上一轮为什么不行：

```text
上一轮理解错了。我要的是"待办清单"，
不是"会议摘要"。两者区别：
待办 = 谁在什么时间做什么事，一行一条；
摘要 = 对内容的概括。
请按待办重做，只输出表格，不要摘要。
```

这样它知道错在哪，下一轮才不会重蹈覆辙。

## 连续追问的正确姿势

追问是为了拿到更精确的信息，不是为了测试它。有效的追问有个特点：**问完你能直接用来做下一步**。

```text
不好：
这个功能怎么样？

好：
你刚才提到"有三种方案"，请按下面的格式列出来：
| 方案 | 适用条件 | 主要风险 |
每个方案一行，风险只写最关键的一条。
```

第二个追问给出了输出格式，拿到的结果可以直接用。

## 控制轮次：三轮原则

给自己一个约束：**同一个任务不超过三轮**。

- 第 1 轮：完整任务
- 第 2 轮：修正
- 第 3 轮：最后确认或微调

三轮还不行，说明任务本身没拆好，或者输入信息不够。这时候回到第 4 章和第 1 章重新判断，而不是继续追问。

三轮原则的好处是防止陷入"越改越乱"的死循环。人一旦进入反复修改，容易忘记最初的目标，最后花的时间比自己写还多。

## 对话中的两个好习惯

### 习惯一：每轮结束确认下一步

```text
这一版可以了。接下来我会让你基于它写邮件，
到时候我会给你收件人信息。
```

这相当于给对话设一个路标。即使中间中断，回来也能接上。

### 习惯二：保存可用的那一版

对话跑了五轮，第三版其实最好用。把它复制出来存好，不要只留在对话记录里。

```text
就用第 3 版，我复制走了。
接下来的修改基于第 3 版，不是最新版。
```

明确"基于哪一版"，避免后续修改建立在错误的版本上。

## 小结

- 一轮对话分三段：给任务、修正收敛、确认收尾。
- 修正用四种话术：指出偏差、引用位置、给示例、缩小范围；记得说"其余不动"。
- 方向错要重来，但说明错在哪；连续两轮不对就回到五要素检查。
- 追问要给出输出格式；同一任务不超过三轮；每轮结束确认下一步、保存可用版本。
