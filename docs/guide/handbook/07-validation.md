# 第 7 章 验收与纠错

拿到初稿到最终交付之间，还有一道工序：验收。这一章给你一个可执行的三层检查法，以及发现问题后的处理路径。

## 为什么要单独讲验收

因为"看起来对"和"能用"是两回事。一段文字读起来通顺，但数据是你没提供的、结论是你不同意的、语气是不适合收件人的——这些都不会在"读起来"这一步暴露。

验收的目标不是挑错别字，而是确认三件事：**来源可靠、判断正确、格式可用**。

## 三层检查法

### 第一层：来源检查（有没有编造）

逐项核对结果里的具体信息：

- **数字**：每个数字都能在你的输入里找到吗？
- **人名、时间、事件**：都是你提供的吗？
- **引用和原话**：和你给的原文一致吗？

发现编造，直接要求替换：

```text
你写的"满意度提升 20%"我没有提供。
把所有我没有提供的数据改成"未提供"，
不要用估算值。
```

::: warning
来源检查必须做，哪怕结果看起来很专业。编造的数字往往看起来最像真的。
:::

### 第二层：判断检查（结论你能接受吗）

检查它做的判断和取舍：

- 它选的重点，和你的判断一致吗？
- 它的语气，适合这份材料的读者吗？
- 它省略的内容，是不是其实很重要？

发现问题，明确修正：

```text
你把"延期"写成了"调整排期"，这不符合事实。
改成"延期"，并说明延期原因是接口延迟，
不要美化。
```

### 第三层：格式检查（能不能直接用）

- 格式对吗？（表格 / 列表 / 段落）
- 长度合适吗？
- 命名、称谓、日期格式符合规范吗？
- 有没有多余的开头引言、结尾总结？

格式问题一次说清：

```text
格式还差三点：
1. 表头改成「事项 / 负责人 / 截止」，不要"任务/人名/时间"
2. 截止日期统一写成 2026-11-20 这种格式
3. 删掉最后一段总结
其他不动。
```

## 一份验收清单

把下面这张表存在手边，每次交付前过一遍：

| 检查项 | 通过标准 |
| --- | --- |
| 所有数字都有来源 | 能在输入材料里找到，没有估算 |
| 所有人名、时间准确 | 和输入一致，没有"未提及"被猜成具体内容 |
| 结论符合我的判断 | 重点、取舍、定性都认可 |
| 语气适合读者 | 正式/口语、简洁/详细，符合场景 |
| 格式正确 | 表格列、列表结构、段落划分符合要求 |
| 长度合适 | 在要求的字数范围内 |
| 没有多余内容 | 没有引言、套话、总结段 |
| 敏感信息已处理 | 没有把不该写的写进去 |

不一定每次全查，但**来源检查和判断检查**不能省。

## 发现问题后的处理路径

```text
来源错误 → 要求替换为"未提供"，不要用估算
判断错误 → 明确告诉它正确的判断是什么，要求改
格式错误 → 列出具体格式要求，说"其他不动"
多处都有问题 → 停止修改，回到五要素重新下发
```

### 情况一：多处都有问题

不要逐条修，逐条修容易顾此失彼。直接重来，但说明上一轮的问题：

```text
这版有三类问题：数据编造、语气太正式、格式不是表格。
我不逐条改了，重新下发完整要求（见下）。
[粘贴完整的五要素提示词]
```

### 情况二：你自己也说不清哪里不对

这时候先别让它改。把结果放一放，问自己："我到底想要什么？"想清楚后再下发，否则会陷入反复修改。

### 情况三：它反复犯同一个错

把这条限制提到最前面，并加重表述：

```text
【最重要的限制】不要编造任何数据。
上一轮你编造了 3 个数字，这是不可接受的。
这次所有数据必须来自我提供的材料，
缺失的明确写"未提供"。
```

## 验收的时间成本

验收通常占整个任务时间的 20%–30%。比如它 3 分钟出初稿，你花 2 分钟检查修改，总共 5 分钟——仍然比自己写 20 分钟快。

如果验收时间超过产出时间，说明提示词写得不够好，回到第 4 章。一个信号：如果你每次都要改格式，说明输出要求没写清楚；如果你每次都要改内容，说明输入或限制没给够。

## 一个验收习惯

验收时**出声读一遍**结果，尤其是要发出去的内容（邮件、汇报、给客户的消息）。出声读能发现默读时忽略的语气问题和逻辑断裂。

```text
出声读的时候问自己：
- 这段话收件人能看懂吗？
- 有没有哪句不像我会说的话？
- 有没有事实错误？
```

## 小结

- 三层检查：来源（有没有编造）、判断（结论你能接受吗）、格式（能不能直接用）。
- 来源检查和判断检查不能省，编造的数字往往看起来最像真的。
- 多处有问题就重来，不要逐条修；说不清哪里不对时先想清楚自己要什么。
- 验收占 20%–30% 时间是正常的；超过这个比例说明提示词该优化。
- 要发出去的内容，出声读一遍再发。
