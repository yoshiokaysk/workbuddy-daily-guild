# 附录

本附录汇总全书模板和速查表，供日常快速取用。

## 附录 A：通用五要素模板

任何任务都从这个模板开始（详见第 4 章）：

```text
目标：[一句话说明要什么结果]
背景：[为什么做、给谁看、当前情况]
输入：[粘贴原始材料]
输出：[格式 / 结构 / 长度 / 语气]
限制：[不要做什么、哪些信息不能用]
```

## 附录 B：常用指令模板速查

### 会议类

**周会纪要**
```text
目标：整理成纪要
输出：一句话结论 / 已定事项列表 / 待办表格（事项·负责人·截止）/ 待确认问题
限制：只写记录里有的，缺失写"未提及"，不写评价
```

**只要待办**
```text
目标：提取待办
输出：表格「事项 / 负责人 / 截止」，按时间排序
限制：只要待办，无负责人写"待认领"
```

### 写作类

**周报**
```text
目标：写周报，发给[领导]
输入：[完成事项 / 数据 / 问题 / 计划]
输出：一句话总结 / 关键数据 / 完成事项 / 问题风险 / 下周计划，600 字内
限制：只写我给的，缺失写"未统计"，风险写"现状+影响"
```

**邮件**
```text
目标：写[主题]邮件给[收件人]
输入：[事实、数据]
输出：主题 + 正文（来意/事实/请求），300 字内
限制：不写客套铺垫，请求明确到"做什么+什么时候"
```

**方案提纲**
```text
目标：列[方案]提纲
输出：各部分要点 + 字数分配，不写正文
限制：先给结构，我确认后再写
```

### 数据类

**数据清洗**
```text
目标：整理成表格「列1/列2/列3」
规则：日期 YYYY-MM-DD；金额两位小数；空值写"未提供"；重复只留第一条
限制：不改数值，无法归类写"其他"
```

**数据说明**
```text
目标：根据数据写情况说明
输出：总体一句 / 3 个关键数据+解读 / 异常项
限制：只用我给的，不推算，不评价
```

### 沟通类

**跨部门同步**
```text
目标：写进度同步
输出：现在到哪步 / 我方事实 / 需要对方做什么+时间，250 字内
限制：不写评价，不涉及他部门内部安排
```

**催办**
```text
目标：写催办
输出：原定X日/当前状态 / 影响 / 请给明确时间
语气：就事论事，不指责
限制：不写"请尽快"，不推测原因
```

### 学习类

**带问题速读**
```text
目标：回答我的问题
输入：[资料]
输出：逐题回答 + 出处引用
限制：只基于资料，没有的写"资料未涉及"
```

**经验提炼**
```text
目标：提炼可复用经验
输出：做对了什么 / 踩了什么坑 / 可复用步骤 / 可复用话术
限制：只从我的记录提炼，写成操作指南不是心得
```

## 附录 D：修正话术速查

| 情况 | 直接说 |
| --- | --- |
| 太啰嗦 | "删掉背景介绍，只保留 A 和 B，其他不要" |
| 某段不对 | "第 X 段改成……，其余段落不动" |
| 语气不对 | "参考这个风格：[示例]，按这个重写" |
| 太散 | "只要 X 部分，按 Y 格式，不超过 Z 条" |
| 方向完全错 | "上一轮理解错了，我要的是 X 不是 Y，区别是……" |
| 三轮还不对 | 停，回到第 4 章重新下发完整五要素 |

## 附录 E：术语表

| 术语 | 含义 |
| --- | --- |
| 五要素 | 目标、背景、输入、输出、限制，说清任务的结构 |
| 初稿思维 | 把 AI 输出当第一版，自己的工作从"写"变成"改" |
| 分层 | 先做结构（提纲/分类），再做内容，避免返工 |
| 来源检查 | 核对结果中的每个具体信息是否来自你的输入 |
| 模板三层 | 固定层、半固定层、输入层 |
| 三轮原则 | 同一任务不超过三轮，三轮不对就回到任务本身 |
| 判断位 | 模板中留给你自己填结论的位置，不让 AI 替你决定 |
| 脱敏 | 把敏感信息替换为代号后再输入 |

## 附录 F：交付前五项检查

```text
□ 来源：数字/人名/时间都来自输入材料？
□ 判断：结论我认可，不是它替我决定的？
□ 格式：能直接用，不用再调？
□ 边界：没有越权承诺，没有敏感信息？
□ 审批：对外内容已经过人工核对和审批？
```
