# 第 12 章 学习与知识管理

工作中经常要学新东西、查资料、把零散的信息沉淀成自己的知识。这一章讲四类任务：资料速读、检索整理、知识沉淀、个人知识库构建。

## 场景一：资料速读

和第 8 章的"长文档速读"类似，但学习场景更关注"我要从中学到什么"。

### 带问题的速读模板

```text
目标：帮我快速理解这份资料，回答我的问题
输入：[粘贴资料]
我的问题：
  1. [比如"这篇文章的核心论点是什么"]
  2. [比如"它提到的方法适用于什么场景"]
  3. [比如"有哪些我没听说过的新概念"]
输出：
  - 逐题回答，每题不超过 150 字
  - 每个答案后面附一句"出处"，引用原文关键句
限制：
  - 只基于资料内容回答，不要补充外部知识
  - 资料里没有答案的问题，写"资料未涉及"
```

### 为什么带问题读

漫无目的地"帮我总结"得到的是平均信息。带问题读，等于你自己控制了注意力，得到的是你现在需要的东西。

## 场景二：检索与整理

需要了解一个陌生领域，或把多个来源的信息放在一起。

### 多源信息整理模板

```text
目标：把下面几份资料整理成一份对比说明
输入：
  资料 A：[粘贴]
  资料 B：[粘贴]
  资料 C：[粘贴]
输出：
  - 表格「主题 / A 的说法 / B 的说法 / C 的说法」
  - 表格后列出"三方一致的点"和"说法冲突的点"
限制：
  - 不要判断谁对谁错
  - 冲突点保留各方原话，不要调和
  - 不要引入资料之外的信息
```

### 让资料"说人话"

遇到看不懂的术语或段落：

```text
目标：解释下面这段话
输入：[粘贴难懂的原文]
输出：
  - 用大白话解释它的意思，100 字以内
  - 列出其中出现的专业术语，每个用一句话解释
  - 举一个生活化的例子帮助理解
限制：
  - 不要改变原意
  - 不要评价这段话说得对不对
  - 例子要贴近[我的工作场景]
```

## 场景三：知识沉淀

把做过的事变成可复用的知识。

### 经验提炼模板

```text
目标：从下面的工作记录中提炼可复用的经验
输入：[粘贴你的工作记录/复盘笔记]
输出：
  - 这次做对了什么（3 条以内，每条说明为什么有效）
  - 这次踩了什么坑（3 条以内，每条说明下次怎么避免）
  - 可复用的步骤（整理成编号清单）
  - 可复用的话术/模板（如果有）
限制：
  - 只从我的记录里提炼，不要补充通用的"最佳实践"
  - 步骤要具体到可直接照做
  - 不要写成"心得体会"，要写成"操作指南"
```

### 模板化沉淀

把你用得顺手的提示词也沉淀下来：

```text
目标：把我下面的提示词整理成可复用的模板
输入：[粘贴你写过的一个提示词]
输出：
  - 把需要每次替换的部分用 [方括号] 标出
  - 分成「固定层 / 半固定层 / 输入层」（见第 5 章）
  - 写一句"适用场景"说明
限制：
  - 不要改动核心要求
  - 标明哪些部分不能省略
```

## 场景四：个人知识库构建

把零散的笔记组织成体系。

### 分类整理模板

```text
目标：给下面这批笔记建立分类体系
输入：[粘贴笔记标题列表，或笔记摘要]
输出：
  - 建议的分类（不超过 6 类），每类说明收录范围
  - 把每条笔记归入一类
  - 列出"跨类"的笔记，说明可以放到哪几类
限制：
  - 分类之间不要重叠
  - 每类至少包含 2 条笔记，否则合并
  - 不要创建"其他"类
```

"不要创建'其他'类"这条限制很重要——"其他"类会变成垃圾堆，等于没分类。

### 从笔记生成速查表

```text
目标：把下面的笔记整理成一张速查表
输入：[粘贴笔记]
输出：表格「什么时候用 / 怎么做 / 注意事项」
限制：
  - "怎么做"一列要具体到可直接执行
  - 每张表不超过 15 行
  - 重复的条目合并
```

## 学习场景的特殊注意事项

### 不要让 AI 替你判断可信度

它可以帮你整理资料，但判断资料是否可信是你的责任。尤其是：

- 数据是否有来源
- 结论是否有依据
- 是否和你已知的事实冲突

### 不要让 AI 替你"学习"

让它解释概念、整理资料是好的；让它"帮你记住"或等于没学。真正形成能力，还是要你自己复述一遍、用一次。

```text
学完一个概念后，用它来检验自己：
"我打算这样向同事解释 [概念]：[你的解释]。
 请指出我说错或说漏的地方，不要重写我的解释。"
```

这个用法让它当"考官"，而不是"答案生成器"，你的印象会深得多。

## 高频错误对照

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| "帮我总结一下这篇文章" | 得到平均信息，不是你要的 | 带问题读 |
| 让它判断多份资料谁对 | 它给的不是可靠判断 | 让它列差异，你自己判断 |
| 沉淀经验时让它"加上最佳实践" | 变成通用套话，没有你的特点 | 限制"只从我的记录里提炼" |
| 分类时允许"其他"类 | 分类体系失效 | 明确禁止"其他"类 |
| 让它"帮你学会" | 等于没学 | 让它当考官，你复述 |

## 验收要点

- 速读/整理：答案都有出处，没有补充资料外的信息。
- 经验沉淀：是从你的记录里来的，不是通用道理。
- 分类：类与类不重叠，没有"其他"类。
- 可信度：由你自己判断，不交给它。

## 小结

- 学习类任务要"带问题读"，由你控制注意力。
- 多源信息整理要保留冲突、不判断对错、不引入外部信息。
- 经验沉淀要"只从我的记录里提炼"，写成操作指南而非心得。
- 分类体系禁止"其他"类。
- 让它当考官检验你的理解，不要让它替你学习。
