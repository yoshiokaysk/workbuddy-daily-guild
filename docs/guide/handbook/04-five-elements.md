# 第 4 章 说清任务：五要素表达法

前面说过，效率差距主要不在产品，而在你怎么交代。这一章给你一个固定的表达结构——五要素。任何任务，只要把这五项填齐，结果通常不会偏。

## 五要素是什么

| 要素 | 回答的问题 | 不写的后果 |
| --- | --- | --- |
| 目标 | 我要什么结果 | 它按自己的理解给，方向可能完全错 |
| 背景 | 为什么要做、处于什么情境 | 给通用答案，不贴合你的情况 |
| 输入 | 有哪些原始材料 | 它编造内容或反复追问 |
| 输出 | 结果要什么格式、长度、结构 | 格式不对，没法直接用 |
| 限制 | 什么不能做、什么不要写 | 包含大量你不要的内容 |

五句话对应五个空。写提示词时，逐项填，不靠灵感。

## 标准模板

```text
目标：[一句话说明要什么结果]
背景：[为什么做，读者是谁，当前情况]
输入：[把原始材料粘贴在这里，或说明材料位置]
输出：[格式 / 结构 / 长度 / 语气]
限制：[不要做什么，哪些信息不能用]
```

这个模板贯穿全书。后面所有场景模板，都是它的具体化。

## 逐项拆解：每一项怎么写

### 目标：一句话，动词开头

好目标的特征：有明确动词（整理、写一封、列出、改成），有明确对象，能被验证。

```text
好：把这段会议记录整理成 5 条待办
不好：帮我处理一下这个会议记录
```

"处理一下"是模糊动词，它不知道是要翻译、总结还是改写。

### 背景：给"为什么"和"给谁看"

背景不需要长，两三句就够，但要有用。关键是回答：这个结果出来后给谁看、用在什么场合。

```text
好：这是给老板看的周报，他只关心结果和风险，不关心过程细节。
不好：这是我公司的周报。
```

第一句直接决定了写作风格，第二句等于没说。

### 输入：材料要完整给出

把原始材料直接贴进去，比描述它更好。

```text
好：[直接粘贴 800 字的会议记录全文]
不好：会议记录有点长，主要说了进度和几个问题。
```

如果你描述材料，它只能基于你的描述再加工，信息在两次转述中已经丢失。

材料太长放不下怎么办？分两次：第一次让它列结构，第二次针对你关心的部分逐段处理（见第 12 章）。

### 输出：格式、结构、长度、语气说全

输出要求是返工率最高的地方。四项都写清楚：

```text
输出：
- 格式：表格
- 列：事项 / 负责人 / 截止日期
- 行数：不超过 8 行
- 语气：客观陈述，不加评价
```

一个对比：

```text
不够好：整理成表格

够用：整理成表格，三列「问题 / 影响 / 建议处理人」，
     不超过 6 行，每行不超过 30 字，不要写总结段
```

### 限制：明确"不要做什么"

限制常常比要求更有效。因为模型倾向于"多做"，你需要明确边界把它拉回来。

常用的限制类型：

| 限制类型 | 示例 |
| --- | --- |
| 不要编造 | 数据只用我给的，缺失的写"未提供"，不要补 |
| 不要扩展 | 不要加背景介绍、不要写结尾总结 |
| 不要臆测 | 只写原文明确提到的，不推测未说的 |
| 不要改变口径 | 延期原因用我的原话，不要润色成客观原因 |
| 长度上限 | 总字数不超过 400 字 |

## 完整示例：从模糊到清晰

### 第一版（模糊）

```text
帮我写个活动总结。
```

结果：一段泛泛的套话，没有数据，没有结论，不能用。

### 第二版（补目标和输入）

```text
目标：写一份活动总结
输入：[粘贴活动流程、参与人数、现场照片说明]
```

结果：有内容了，但格式随意，长度失控。

### 第三版（五要素齐全）

```text
目标：写一份面向管理层的活动总结
背景：这次是公司内部技术分享会，管理层需要判断下次是否继续投入
输入：[粘贴活动流程、参与人数 86、满意度 4.6/5、3 条现场反馈原文]
输出：结构为「一句话结论 / 关键数据 / 做得好的 2 点 / 待改进的 2 点」，
      总字数 500 字以内，语气客观
限制：不要写套话和形容词堆砌；数据只用我给的，缺失项写"未统计"；
      待改进部分要具体，不要写"继续优化"这类空话
```

第三版的结果，通常改几个词就能用。

## 五要素的简化用法

日常高频任务不需要每次写全。用熟之后可以用简写：

```text
目标：把这段转成三条待办
输出：表格，负责人/事项/截止
限制：不要补充原文没有的信息
[粘贴原文]
```

背景省略是因为你已经知道这是内部周会；输入直接贴；目标和输出仍然明确。简写的前提是你心里清楚被省略的项是什么。

::: warning
新手不要一开始就用简写。先用完整模板写十几轮，等"哪些不能省"形成直觉后再简化。
:::

## 常见错误对照

| 错误 | 表现 | 修正 |
| --- | --- | --- |
| 目标里塞限制 | "写个简短的、不要太长的总结" | 目标写"写总结"，长度写到输出项 |
| 背景写成闲聊 | "最近我们部门挺忙的" | 背景写"读者是谁、判断标准是什么" |
| 输入用描述代替 | "数据大概是上周那些" | 直接贴数据 |
| 输出只写格式 | "给我表格" | 写清列、行数、字数、语气 |
| 限制写成期望 | "希望准确一点" | 写"缺失数据标为未提供，不要推测" |

## 小结

- 五要素是目标、背景、输入、输出、限制，逐项填，不靠灵感。
- 目标用动词开头、可验证；背景写"给谁看、为什么"；输入直接贴材料。
- 输出要写全格式、结构、长度、语气；限制明确"不要做什么"。
- 模糊提示词到清晰提示词的差距，就是返工时间的差距。
