# 第 15 章 团队场景下的应用

当多人一起用 WorkBuddy，问题从"我怎么用"变成"大家怎么用得一致"。这一章讲共享模板、协作规范和团队边界。

## 团队用的三个目标

1. **产出可对齐**：同一个任务，不同人做出来格式相近，能直接合并。
2. **经验可复用**：一个人调好的模板，全组都能用。
3. **风险可控**：涉及数据和对外内容时，有统一的规范。

## 建立团队模板库

### 模板库的组织方式

```text
团队模板库/
  01-会议/
    周会纪要
    客户会议纪要
  02-写作/
    周报
    项目汇报
  03-数据/
    日报
    数据说明
  04-沟通/
    跨部门同步
    催办
```

结构按场景分，不按人分。按人分会导致离职后模板失效。

### 模板入库的标准

一个模板要进团队库，至少满足：

- **至少两人验证过**：一个人觉得好用不算，换个人试试还能用才行。
- **写了适用场景**：什么情况下用、什么情况下别用。
- **标了不能省的部分**：新手容易漏掉哪些限制。

```text
# 模板：周会纪要
适用场景：部门内部周会，纪要发给参会同事
不适用场景：客户会议（用"客户会议纪要"模板）
不能省：输出结构第 3 项（待办表格）和限制第 1 项（不推测）
维护人：[岗位，不写具体姓名]
```

最后一条写岗位不写姓名，人员变动时不用改。

### 模板的维护节奏

每月一次，15 分钟：

```text
1. 收集本月使用反馈（哪条限制被证明有效、哪条被反复删掉）
2. 更新模板，在迭代记录里写明改动原因
3. 删掉连续两个月没人用的模板
```

## 团队协作规范

### 规范一：命名与存放统一

所有人按同一规则命名产出、存到同一位置。否则"可对齐"无从谈起。

```text
命名：日期—场景—主题
存放：团队产出区/年份/月份/
```

### 规范二：验收标准统一

团队共用一份第 7 章的验收清单，尤其统一"来源检查"的要求：

```text
团队约定：
- 所有对外数据必须全量人工核对，不允许抽样
- 对外邮件/材料必须出声读一遍
- 涉及金额、合同的产出，必须第二人复核
```

### 规范三：标注"AI 辅助生成"

在需要透明的场合，约定是否标注：

```text
对外正式材料：[按公司规定决定是否标注]
内部文档：建议标注"AI 辅助整理，已人工核对"
```

标注"已人工核对"很重要——它明确了责任在人，不在工具。

## 团队边界：什么不能交给 AI

团队场景下，边界要比个人使用更严格：

| 类型 | 能否交给 AI | 处理方式 |
| --- | --- | --- |
| 内部公开信息 | 可以 | 正常使用 |
| 公司内部数据 | 谨慎 | 按公司规定，必要时脱敏 |
| 客户数据 | 通常不行 | 脱敏，或不用 |
| 合同、财务、人事材料 | 不建议 | 人工处理 |
| 对外正式承诺 | 不允许 | 人工撰写与审批 |

::: warning
涉及客户隐私、商业机密、人事信息的材料，按公司合规要求处理。不确定时，按"不输入"处理。第 16 章展开讲安全边界。
:::

## 让团队用起来的方法

工具推广的常见失败原因：发了模板，没人用。有效方法：

### 方法一：从一个人的成功案例开始

不要一上来要求全组统一。先让一个人用某个模板做出明显更快的成果，拿这个案例给大家看。看到实际效果，别人自然会问"你怎么做的"。

### 方法二：把模板放进现有流程

不要让大家"额外打开一个工具"。把模板嵌进已有的工作环节：

```text
周会结束 → 模板已经在会议文档里 → 填材料 → 出纪要
```

模板出现在流程里，使用就是自然的；模板放在流程外，使用就需要额外记忆。

### 方法三：指定"模板维护人"

每个场景有一个维护人（按岗位指定），负责收集反馈和更新。没人维护的模板库，三个月后就过时了。

## 团队协作常见问题

| 问题 | 表现 | 解决 |
| --- | --- | --- |
| 各用各的 | 产出格式不一，无法合并 | 建立共享模板库，统一格式 |
| 模板过时 | 还在用半年前的模板 | 指定维护人，月度更新 |
| 质量不齐 | 有人验收仔细，有人直接用 | 统一验收清单，明确红线 |
| 数据风险 | 把客户数据贴进去 | 明确数据分级，写进规范 |
| 责任不清 | 出错后互相推 | 规定"产出需标注已人工核对" |

## 一个团队规范的示例

```text
【团队 WorkBuddy 使用约定 v1.0】

1. 模板库位置：[内部文档链接]，按场景分类
2. 产出存放：[共享目录]，命名 日期—场景—主题
3. 验收：使用统一验收清单（见指南第 7 章）
4. 红线：
   - 客户数据不输入
   - 对外数据全量核对
   - 对外材料人工审批后发出
5. 维护：每个场景指定岗位维护人，每月更新
6. 标注：对外材料按公司规定；内部文档标注"AI 辅助整理，已人工核对"
```

这份约定不需要长，一页纸就够。关键是所有人都看得到、记得住。

## 小结

- 团队用好的三个目标：产出可对齐、经验可复用、风险可控。
- 模板库按场景分不按人分；入库需两人验证、写适用场景、标不可省项、写岗位不写姓名。
- 团队规范统一命名存放、验收标准、AI 辅助标注。
- 团队边界更严格：客户数据、合同财务人事、对外承诺不交给 AI。
- 推广从一个人的成功案例开始，把模板嵌进现有流程，指定维护人。
