# 第 10 章 表格与数据处理

日常工作中大量时间花在"把数据整理成表""把表变成报表"上。这一章讲三类任务：数据整理清洗、报表生成、简单分析。

::: warning
重要前提：WorkBuddy 不擅长精确计算，也不应该替你做财务或统计上的最终判断。让它做"整理、格式化、归类、描述"，计算结果你自己复核。涉及金额、合同、对外报送的数据，必须人工核对。
:::

## 场景一：数据整理与清洗

把杂乱的数据变成规整的表格。

### 操作步骤

1. **明确目标格式**：表头有哪些列？每列什么格式？
2. **给原始数据**：直接贴，不要描述。
3. **写清洗规则**：空值怎么处理、重复怎么合并、格式怎么统一。
4. **抽样验收**：检查前几行和几行特殊的，不要全表逐行看。

### 清洗模板

```text
目标：把下面的数据整理成规整表格
输入：[粘贴原始数据]
输出：表格，列依次为「日期 / 项目 / 金额 / 状态」
规则：
  - 日期统一为 YYYY-MM-DD
  - 金额保留两位小数，去掉货币符号
  - 状态只能写「完成 / 进行中 / 延期」三者之一
  - 空值写「未提供」，不要留空
  - 重复行只保留第一条
限制：
  - 不要修改任何数值
  - 无法归类的状态写「其他」，不要猜
```

### 常见的清洗规则清单

按需取用，写进"规则"里：

| 问题 | 规则写法 |
| --- | --- |
| 日期格式乱 | 日期统一为 YYYY-MM-DD |
| 金额带符号 | 去掉货币符号，保留两位小数 |
| 有空值 | 空值写"未提供"，不要留空 |
| 有重复 | 完全相同的行只保留第一条 |
| 分类不统一 | 状态只能从 A/B/C 中选 |
| 有多余空格 | 去掉首尾空格 |
| 单位不一致 | 统一换算成 [单位]，换算过程单独列出 |

### 抽样验收怎么做

不要逐行核对（那还不如自己做）。检查：

- 前 3 行：格式对不对
- 含空值的行：是否正确标为"未提供"
- 含特殊字符的行：是否处理正确
- 最后 1 行：有没有漏

如果这四类都正确，整表通常没问题。

## 场景二：报表生成

把整理好的数据变成一段文字描述或固定格式的报表。

### 模板：数据转文字描述

```text
目标：根据下面的数据写一段情况说明
输入：[粘贴整理好的数据表]
输出：
  - 第一段：总体情况（一句话）
  - 第二段：3 个关键数据点，每个带一句解读
  - 第三段：值得注意的异常或变化
  总字数 400 字
限制：
  - 只用我给的数据，不要推算我没给的指标
  - 解读要客观，不要写"表现优异"这类评价
  - 异常项如果原因不明，写"原因待确认"
```

### 模板：固定格式的日报/月报

```text
目标：按固定格式生成数据日报
输入：[粘贴当日数据]
输出：
  【今日数据】
  - 总数：[ ]  完成：[ ]  延期：[ ]
  【变化】与前一日对比，列出上升/下降的项
  【需关注】列出异常项，不超过 3 条
限制：
  - 对比只用我提供的数据
  - 没有前一日数据时写"无对比数据"
```

## 场景三：简单分析

让 WorkBuddy 帮你"看出点什么"，但记住：它给的是思路，结论你自己下。

### 模板：描述性分析

```text
目标：从下面的数据里找出值得关注的现象
输入：[粘贴数据表]
输出：
  - 列出 5 个现象，每个包含「现象描述 + 支持数据」
  - 按重要程度排序
  - 最后列出 3 个你建议我进一步核查的方向
限制：
  - 只描述数据里有的，不要解释原因
  - 不要给"应该怎么做"的建议
  - 现象必须附带具体数据支撑
```

注意限制里的"不要解释原因"——它很容易把推测当成事实写进"现象"里。

### 模板：对比分析

```text
目标：对比 A 和 B 两组数据的差异
输入：[粘贴两组数据]
输出：表格「指标 / A / B / 差异」，最后列出差异最大的 3 项
限制：
  - 差异用"增加/减少 X"描述，不要写"更好/更差"
  - 不解释差异原因
  - 数据口径不同的指标标注出来，不要直接对比
```

## 处理大表格的策略

表格太大，一次贴不下怎么办？

### 策略一：先给表头和样本

```text
这是表格的表头和前 5 行：[粘贴]
请确认你理解了每列的含义，先用一句话复述每列是什么。
```

确认理解后，再分批给数据。

### 策略二：分批处理再合并

把表格按行分成几批，用同一规则分别处理，得到几张格式一致的小表，再按第 8 章的方法合并。

### 策略三：只要规则，不要它处理

如果任务极其机械（比如给 500 行数据统一日期格式），可以不要它处理数据，而是让它给你一段处理规则或公式，你在表格软件里执行。这更可靠。

```text
目标：告诉我怎么在 Excel 里完成以下清洗
输入：[描述数据问题]
输出：具体操作步骤或公式，可直接照做
限制：不要帮我处理数据，只给方法
```

## 高频错误对照

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 让它"算一下总数" | 算错且你不易发现 | 让它整理，你用表格软件算 |
| 数据贴一半 | 结果基于不完整数据 | 给完整数据或分批处理 |
| 没写空值规则 | 它自己填空值 | 明确"空值写未提供" |
| 让它分析原因 | 推测被当成事实 | 限制"只描述，不解释原因" |
| 对外数据直接用了它的结果 | 风险极高 | 必须人工逐项复核 |

## 验收要点

数据类任务的验收：

- **抽样检查**：前几行、特殊行、最后一行
- **数值核对**：所有数值和原文一致，没有被"优化"
- **规则执行**：空值、重复、格式是否按规则处理
- **没有推算**：它有没有给出你没提供的指标
- **对外数据**：100% 人工核对，不能抽样

## 小结

- 让 WorkBuddy 做整理、格式化、归类、描述，不做精确计算和最终判断。
- 清洗任务要写全规则：日期、金额、空值、重复、分类、空格、单位。
- 报表生成要限制"不推算、不评价"。
- 分析任务要限制"只描述现象、不解释原因"。
- 大表格分批或只让它给方法；对外数据必须全量人工核对。
