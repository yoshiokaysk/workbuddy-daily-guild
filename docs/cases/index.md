# 个人案例集

这里收录由个人开发者贡献的真实实践案例。每个案例都会说明它解决了什么场景、用了哪些技术、如何执行，以及最终交付了什么结果。

案例通过完整性、安全性和可读性审核后即可发布；经过进一步复现和编辑的经典案例，未来可能被收录进《WorkBuddy 实战蓝皮书》正文。

## 如何提交个人案例

1. 先搜索现有案例和[蓝皮书目录](/bluebook/)，确认场景或任务没有重复。
2. 阅读[个人案例投稿指南](/community/case-contributing)，按统一格式准备内容。
3. 把案例放到 `docs/cases/submissions/<案例名>/index.md`，配图放进同目录的 `assets/`。
4. 提交 Pull Request，并选择个人案例专用 PR 模板。

网站构建时会自动读取每个个人案例的标题、分类、Skills、作者和简介，无需手动修改本页。
